# 矿山尾矿库监测计划与异常处置审阅平台

基于Angular、Angular Material、NgRx、Angular Router、RxJS、HttpClient、MapLibre GL、Turf.js、Nx和TypeScript的独立前端工程。无后端时自动使用本地模拟数据，界面内操作保留版本和审计。

## 功能

- 位移、水位、渗流、降雨监测点，MapLibre测点图层和Turf巡检路线长度。
- 报警值、变化速率与阈值版本查看。
- 异常队列、现场复核、证据、复测评估和专业异议并存。
- 处置方案、重大异常应急联动、负责人审批和关闭条件校验。
- 原始读数只读，所有修订形成独立版本和审计时间线。
- JSON审阅包导出。

## 异常处置统一版本链

异常、现场复核、专业意见、处置方案与审计接在同一条单调递增的版本链（`Anomaly.chain`）上：

- **每个动作记录所见版本**：所有写请求携带 `baseVersion`，审计同时记录所见版本与生效版本。
- **先到生效、后到留痕**：保存时做版本 CAS——`baseVersion === 链头`才提交原子修订；后到的旧窗口保存不会覆盖已生效签批/审计，而是转成「冲突草稿」并保留完整依据快照，可对齐链头后重提。
- **意见联动**：专业意见补充/撤回与触发动作同一修订生效。未执行（待审批）方案立即置为「已失效」并退回重算；执行中方案冻结保留原签批依据（`plan.basis`），同时追加一条「意见联动复核」。
- **失败写可恢复**：写请求先入本地 WAL（outbox，localStorage 持久化），通道失败时保留完整审阅版本快照；可逐条或全部重试，刷新后自动恢复。
- **重放幂等**：每个命令有 `commandId`，重试/重放命中已应用命令时判定为重复，不会重复追加意见、复核或审计结论（联动结论挂在同一修订上，天然只生效一次）。

纯函数引擎位于 `src/app/domain/version-chain.ts`，可独立于 UI 测试。异常处置页提供「旧窗口」与「写入中断」两个演练开关，用于复现两位审阅员并发保存与失败恢复。

端口为`18462`。

```bash
npm install
npm run build
npm run dev
```
