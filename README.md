# 矿山尾矿库监测计划与异常处置审阅平台

基于Angular、Angular Material、NgRx、Angular Router、RxJS、HttpClient、MapLibre GL、Turf.js、Nx和TypeScript的独立前端工程。无后端时自动使用本地模拟数据，界面内操作保留版本和审计。

## 功能

- 位移、水位、渗流、降雨监测点，MapLibre测点图层和Turf巡检路线长度。
- 报警值、变化速率与阈值版本查看。
- 异常队列、现场复核、证据、复测评估和专业异议并存。
- 处置方案、重大异常应急联动、负责人审批和关闭条件校验。
- 原始读数只读，所有修订形成独立版本和审计时间线。
- JSON审阅包导出。

## 异常处置统一版本链

异常、现场复核、专业意见、处置方案、审计共用同一条单调递增版本链（核心逻辑见 `src/app/domain/version-chain.ts`）：

- **动作记录所见版本**：每次保存携带 `baseVersion`（窗口所见版本）、`writeId` 与窗口时间戳，链节点与审计记录“所见Vx → 生效Vy”。
- **先到生效 / 后到留冲突**：`baseVersion` 与当前版本一致才生效；后保存的旧窗口不覆盖已生效签批和审计，内容连同依据版本保留为「冲突草稿」，可载入表单或对照当前版本核对后作为新版本提交。
- **意见联动方案**：专业意见补充或撤回时，未执行（待审批/已签批未执行）方案立即失效、归档并回到“原因调查中”重算；执行中方案保留签批时锁定的依据快照继续执行，并自动追加一条现场复核。
- **失败可恢复、重放幂等**：勾选“模拟写入失败”后，完整审阅版本进入 `pendingWrites`（随审阅包导出），可一键恢复重放；按 `writeId` 去重，重放不重复追加结论，恢复时若已被他人抢先则转冲突草稿。

